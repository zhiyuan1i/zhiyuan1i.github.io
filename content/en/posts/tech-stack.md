## Tech Stack

This site is built with the following technologies:

| Technology | Purpose |
|------------|---------|
| [Flutter](https://flutter.dev/) | Layout, routing, and the bilingual interface |
| [liquid_glass_easy](https://pub.dev/packages/liquid_glass_easy) | Real refraction for navigation and selected cards |
| [flutter_markdown_plus](https://pub.dev/packages/flutter_markdown_plus) | Markdown article rendering |
| [flutter_math_fork](https://pub.dev/packages/flutter_math_fork) | LaTeX equation rendering |
| Dart | Static files and the Markdown content service |

## Content and Delivery

Articles are still written in Markdown. The same source files power both the Flutter interface and crawler output. A browser opens the Flutter page at an article URL, while `curl`, crawlers, and requests declaring `Accept: text/markdown` receive the original Markdown. Post indexes, tags, archives, RSS, and the sitemap are generated by the same content service.

## Interface and Performance

- **Liquid glass**: Real refraction is reserved for navigation, post cards, and a few key controls; long articles and dense tag lists use a lightweight material
- **Dark and light modes**: Follow the system theme, with a manual override
- **Chinese and English**: Chinese browsers default to Chinese and all other languages to English; manual selection and deep links take precedence
- **Responsive design**: Desktop and mobile use dedicated navigation layouts
- **Accessibility**: Interactive controls expose semantic labels and keyboard interaction
